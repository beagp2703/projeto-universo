# 🌌 Explorando o Universo

Uma página web educativa desenvolvida em **React.js**, criada com o objetivo de praticar a construção de interfaces utilizando componentes, HTML semântico, CSS moderno e princípios básicos de acessibilidade e responsividade.

---

## 📌 O que é?

O **Explorando o Universo** é uma aplicação web desenvolvida para apresentar informações introdutórias sobre o universo de forma simples, organizada e visualmente agradável.

O projeto foi desenvolvido como uma atividade prática de aprendizado em **React.js**, com foco na criação e organização de componentes reutilizáveis.

A aplicação apresenta:

- 🌎 Informações sobre planetas;
- ⭐ Curiosidades sobre estrelas;
- 🚀 Conteúdos introdutórios sobre o universo;
- 🧩 Estrutura dividida em componentes React;
- 📱 Layout responsivo para diferentes tamanhos de tela;
- ♿ Recursos básicos de acessibilidade;
- 🎨 Estilização organizada em arquivos CSS específicos para cada componente.

### 🎯 Objetivos alcançados

Com o desenvolvimento deste projeto, foi possível praticar:

- Criação de componentes com React;
- Utilização de JSX;
- Organização de uma aplicação em componentes;
- Estruturação semântica do conteúdo;
- Separação entre estrutura e estilização;
- Utilização de Flexbox e CSS Grid;
- Desenvolvimento responsivo;
- Aplicação de boas práticas de acessibilidade;
- Organização de arquivos em um projeto React.

## 🚀 Como Executar o Projeto

Para executar o projeto localmente, é necessário ter algumas ferramentas instaladas no computador.
